# NEPHROPREDICT-AI-BASED-EARLY-CKD-PREDICTION-UNDER-CLASS-IMBALANCE-CHALLENGE
NephroPredict is an AI-based system for early detection of Chronic Kidney Disease (CKD). It preprocesses patient data, handles class imbalance using SMOTE, and applies ML models like Random Forest, Decision Tree, Logistic Regression, KNN, and Naive Bayes to provide accurate predictions and support early intervention.
